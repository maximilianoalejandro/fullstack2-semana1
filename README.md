# MediCare

Sitio web de un centro de consultas médicas con 4 especialidades y sus
servicios. Hecho con HTML5 y CSS3.

## Estructura

```
consultamedica-s1/
├── index.html              Inicio: 4 especialidades
├── medicina-general.html   3 servicios
├── pediatria.html          3 servicios
├── dental.html             3 servicios
├── kinesiologia.html       3 servicios
├── css/styles.css          Estilos compartidos
└── img/                    Imágenes del inicio
```

## Cómo abrir

Abre `index.html` en el navegador, o usa Live Server en VS Code.

## Características

- 5 páginas con navegación y enlace para volver al inicio.
- 4 especialidades con sus servicios (imagen, nombre, descripción, precio y descuento).
- Estilos con variables, animaciones y diseño responsivo.
